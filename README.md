=======================================
PENJELASAN FITUR DARI WEBSITE PORTFOLIO
=======================================

Saya membuat slicing website portfolio untuk tugas 1 praktikum PWEB. website ini berisi HTML, CSS dan javascript(DOM).

1. NAVBAR
Di bagian paling atas halaman terdapat menu yang bertujuan sebagai navigasi ke bagian dari website tertentu.
misalnya, jika memencet 'Kontak' maka halaman web akan bergulir ke bagian kontak yang berada di Bawah.
selain itu, menu ini sangat responsive dan akan menyesuaikan ukuran layer yang saat ini dipakai atau user me-resize
ukuran browser. jika layer dalam keadaan landscape, semua pilihan menu tertampil di tengah atas halaman. sebaliknya
semua pilihan navigasi di sembunyikan ke dalam menu dropdown dengan ikon tiga garis di sebelah kanan atas halaman
jika user mengakses website melalui smartphone.

3. HOME
Bagian home berisi teks judul, text paragraph, foto profil, serta link social media. ini adalah halaman awal yang
dilihat user Ketika pertama kali mengunjungi website ini. foto profil, teks, hyperlink, dan vector belakang dibentuk
dengan sedemikian rupa menggunakan CSS agar memiliki visual yang menarik. elemen yang resposif terhadap ukuran layar
adalah foto profil dan teks. jika layar landscape kedua elemen tersebut akan bersampingan, di layar portrait mereka
akan bertumpuk atas-bawah sementara elemen link tetap di kedua situasi.

5. ABOUT ME
bagian 'tentang aku' menyangkut teks header dan paragraph serta tombol untuk mendownload CV. jika user memencet tombol
itu maka mereka akan di arahkan ke file CV yang berada di Google drive. tidak ada elemen yang berubah jika halaman website
dalam mode landscape atau portrait.

7. PROJECTS
bagian ini memuat 2 kartu berisikan thumbnail project dan judulnya.

8. CONTACT ME
contact me berfungsi jika user ingin mengirimkan pesan melalui email. dibagian ini berisi input nama, email, no hp, tempat
untuk menulis pesan dan tombol submit. jika input masih kosong atau salah penulisan maka akan muncul pop up peringatan.
